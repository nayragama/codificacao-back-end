# Aula 01 — Revisão de Node.js e NPM

## 📚 Descrição da atividade

Nesta atividade, desenvolvi um programa em **JavaScript** utilizando o módulo nativo `os` do Node.js para realizar um diagnóstico do computador.

O programa exibe as seguintes informações:

- Sistema operacional utilizado;
- Memória RAM total;
- Memória RAM disponível;
- Quantidade de núcleos do processador;
- Modelo do processador;
- Velocidade do processador em MHz.

Também pratiquei a organização dos arquivos do projeto, a utilização do **NPM** e o versionamento do código com **Git e GitHub**.

## 🛠️ Tecnologias utilizadas

- JavaScript;
- Node.js;
- NPM;
- Git;
- GitHub;
- Visual Studio Code.

## ▶️ Como executar

No terminal, dentro da pasta da atividade, execute:

```bash
node diagnostico.js
