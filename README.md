# Codificação Back-End

Este repositório reúne os projetos, exercícios e anotações desenvolvidos para o aprendizado e prática em **desenvolvimento Back-End**. O foco principal está na construção de APIs RESTful, gerenciamento de servidores e manipulação de fluxos de dados utilizando o ecossistema JavaScript.

---

## 🎯 Objetivos

- Compreender a arquitetura de aplicações Back-End e o funcionamento do modelo cliente-servidor.
- Desenvolver APIs RESTful eficientes utilizando **Node.js** e **Express**.
- Dominar o uso do **NPM** para gerenciamento de dependências e pacotes.
- Aplicar boas práticas de versionamento de código com **Git** e **GitHub**.
- Implementar rotas, middlewares e tratamento de erros no servidor.

---

## 📚 Tópicos e Conteúdo

- **Introdução ao Back-End**: Conceitos básicos, requisições HTTP (GET, POST, PUT, DELETE) e códigos de status.
- **Ambiente de Desenvolvimento**: Configuração do ambiente com Node.js e gerenciamento de scripts no package.json.
- **Servidores e Rotas**: Criação de servidores web e controle de rotas com Express.
- **Middlewares**: Validação de dados, manipulação de headers e logs de requisição.
- **Versionamento de Código**: Controle de código com branches, commits semânticos e sincronização com repositório remoto.

---

## 🛠️ Ferramentas e Tecnologias

- **JavaScript (ES6+)**: Linguagem base utilizada no projeto.
- **Node.js**: Ambiente de execução do JavaScript no servidor.
- **Express.js**: Framework web minimalista para construção da infraestrutura de rotas e APIs.
- **NPM (Node Package Manager)**: Gerenciador de pacotes para instalação e controle de bibliotecas.
- **Git**: Sistema de controle de versão distribuído.
- **GitHub**: Plataforma para hospedagem do código-fonte e colaboração.
