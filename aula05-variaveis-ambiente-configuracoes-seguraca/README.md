# Aula 05 — Variáveis de ambiente e configurações

## 📚 Descrição da atividade

Nesta atividade, pratiquei o uso de **variáveis de ambiente** em um projeto Node.js. Organizei configurações como a porta do servidor, uma chave de pagamento de teste e a URL de conexão com o banco de dados em um arquivo `.env`.

Também criei um arquivo `.env.example` com os nomes das variáveis para mostrar quais configurações são necessárias para executar o projeto, sem incluir os valores utilizados no ambiente local.

## 🎯 O que pratiquei

- Separar configurações do código da aplicação;
- Utilizar um arquivo `.env` para valores locais;
- Criar um `.env.example` como modelo;
- Organizar dados de configuração que exigem cuidado, como chaves e URLs de conexão.

## ⚙️ Configuração

Crie um arquivo `.env` com base no `.env.example` e preencha os valores necessários para executar o projeto. Não publique chaves reais ou senhas no repositório.

## 🛠️ Tecnologias utilizadas

JavaScript, Node.js, NPM, Git e GitHub.
